# MDOF suspensiones

Herramienta HTML de un solo archivo (`index.html`) para sólidos rígidos sobre suspensiones elásticas (6·N gdl): deformación estática por casos de carga, frecuencias naturales y Campbell, respuesta forzada, choque en el tiempo (con gaps), choque modal (SRS / especificación), vista 3D animada e informe.

Abre `index.html` en el navegador. No necesita instalación ni servidor.

## Uso sin conexión e instalación

- **Archivo suelto:** `index.html` no depende de nada externo; abierto desde el disco funciona sin internet.
- **Desde GitHub Pages:** abre la dirección una vez con conexión y usa «Instalar» en Chrome (icono de la barra de direcciones o menú ⋮). Después funciona sin conexión; con conexión se actualiza sola.
- **Al publicar una versión nueva:** cambia `V` en `sw.js` y el número de versión en `index.html`.
