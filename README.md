# MDOF suspensiones

Herramienta HTML de un solo archivo (`index.html`) para sólidos rígidos sobre suspensiones elásticas (6·N gdl): deformación estática por casos de carga, frecuencias naturales y Campbell, respuesta forzada, choque en el tiempo (con gaps), choque modal (SRS / especificación), vista 3D animada e informe.

Abre `index.html` en el navegador. No necesita instalación ni servidor.
